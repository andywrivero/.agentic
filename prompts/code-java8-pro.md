# Java 8 Prompts

Copy one template, fill in the brackets, and paste it. Each one names its skill so the skill loads. Use these only in projects that target Java 8.

## Implement

Implement [feature] in [class/package]. Use the java8-pro skill to keep the code Java 8 compatible and idiomatic. Follow the existing design and do not modernize unrelated code.

## Refactor

Refactor [class/method] to [goal] without changing behavior. Use the auto-simplify skill for the cleanup and the java8-pro skill to keep it Java 8 compatible.

## Review only

Use the java8-pro skill to review [files/diff] for Java 8 compatibility, including APIs and dependencies. Do not edit. Report findings as: file:line, issue, Java 8 alternative.
