# Test Backfill Prompts

Copy one template, fill in the brackets, and paste it. Each one names its skill so the skill loads.

## Cover a change

Use the test-backfill skill to add tests for the code changed in [this task / the staged diff / branch vs main]. Cover nulls, boundaries, and error paths, and mock external dependencies. Report any bugs instead of fixing them.

## Cover a class or area

Use the test-backfill skill to backfill tests for [class/package]. Show the gaps and chosen cases first, then write and run the tests and the mutation check.

## Gap analysis only

Use the test-backfill skill to analyze [class/package] for untested behaviors and edge cases. Do not write tests. Report findings as: behavior, missing cases, risk.
