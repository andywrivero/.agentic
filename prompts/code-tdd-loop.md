# TDD Loop Prompts

Copy one template, fill in the brackets, and paste it. Each one names its skill so the skill loads.

## Build a feature test-first

Use the tdd-loop skill to implement [feature] in [class/package]. Show the test list first, then run red-green-refactor for each item and report each cycle.

## Fix a bug test-first

Use the tdd-loop skill to fix [bug: input, expected, actual]. Start with a test that reproduces it and fails, then fix it with the minimum change.

## Continue from a design note

Use the tdd-loop skill to implement the design note above. Turn its acceptance criteria into the test list.
